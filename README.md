Вголове — это VR-галерея (музей / арт-пространство), в которой на стенах развешаны постеры любимых фильмов, обложки музыкальных альбомов и другие арт-объекты автора. Пользователь надевает VR-шлем, свободно ходит по виртуальным залам и подходит к любому постеру: при приближении включается голосовая запись автора с личным описанием — почему этот фильм или альбом важен, что в нём особенного. Галерея живая: постеры можно снимать со стен, перевешивать на другие места, а можно просто взять и бросить.
